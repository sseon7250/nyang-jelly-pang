# 🫧 냥젤리 팡팡 (시안 v1.1)

광고를 붙일 킬링타임용 게임 시안입니다. **단일 `index.html` 파일 하나**로 동작하며,
외부 CDN·폰트·이미지 요청이 전혀 없어서 인터넷 없이도(오프라인, `file://`) 그대로 실행됩니다.

## 실행 방법
1. `index.html` 을 폰으로 보내서 Chrome으로 열기 (파일 앱 → Chrome으로 열기)
2. 또는 웹에 올리기: 파일 하나만 아무 정적 호스팅(Netlify·Vercel·GitHub Pages·카페24 등)에 올리면 끝
3. PC에서 확인: 파일 더블클릭

## 게임 모드
| 모드 | 내용 |
|---|---|
| 🐾 클래식 (25턴) | 25턴 안에 목표 점수를 넘기면 다음 스테이지. 남은 턴은 턴당 40점 보너스 |
| ⏱️ 60초 타임어택 | 60초 카운트다운 동안 최대한 높은 점수에 도전. 0초가 되면 종료 |

시작 화면에서 두 모드 중 하나를 골라 플레이합니다. 타임어택 최고 기록은 클래식 기록과
따로 저장됩니다(`nyangJelly.bestTime.v1`).

## 게임 규칙
| 요소 | 내용 |
|---|---|
| 보드 | 8×8, 파스텔 고양이 발바닥 젤리 5색(코랄핑크·버터옐로우·민트·스카이블루·라벤더) |
| 터뜨리기 | 같은 색 2개 이상을 터치 → 연결된 젤리가 한 번에 팡 (중력 낙하 + 파티클 + 찰진 스쿼시 애니메이션) |
| 츄르 폭탄 | 한 번에 **5~6개** 터뜨리면 생성. 터뜨리면 주변 3×3 폭발 |
| 무지개 젤리 | 한 번에 **7개 이상** 터뜨리면 생성. 터뜨리면 가장 많은 색 전체 제거 |
| 콤보 | 2.8초 안에 계속 터뜨리면 x1.25 ~ x2.5 배 점수 |
| ⚡ 피버 타임 | **4콤보** 달성 시 **5초간** 발동. 보드 테두리 글로우 + 상단 FEVER 배너, 그동안 획득 점수 **×2** |
| 🔥 막판 긴장감 | 클래식 **남은 턴 3 이하**, 타임어택 **남은 시간 10초 이하**일 때 화면 가장자리에 붉은 맥박 비네트 + 째깍·심장박동 효과음 (음소거 시 무음) |
| 🎁 이스터에그 | 고양이 마스코트를 **1.5초 안에 5번 연타**하면 스테이지당 1회, 숨겨진 황금 츄르 발견! 랜덤 젤리 1~2개가 츄르 폭탄/무지개 젤리로 변신 |
| 기록 | 최고 점수 `localStorage` 저장 (클래식 `nyangJelly.best.v1`, 타임어택 `nyangJelly.bestTime.v1`) |

## 광고 자리 (수익화 설계)
- **하단 배너 슬롯**: `index.html` 의 `<div class="ad-slot">…</div>` (높이 58px)
  → 실제 광고 코드(AdSense 반응형, AdMob 웹, 애드핏 등)를 이 `div` 안에 넣으면 됩니다.
  시안에서는 점선 박스 + "배너 광고 영역" 안내 문구로 자리만 표시합니다.
- **보상형 광고**: 게임오버 창의 `📺 광고 보고 이어하기` 버튼
  → 클래식은 **+5턴**, 타임어택은 **+15초** 지급. 지금은 2초 카운트다운 후 보상을 주는 **테스트 동작**입니다.
  실제 연동 시 `showRewardAd()` 안에서 광고 SDK를 호출하고,
  광고 시청 완료 콜백에서 `grantAdReward()` 를 부르면 그대로 보상이 지급됩니다.

```js
// 예: AdMob 보상형 연동 지점 (index.html 안)
function showRewardAd() {
  // TODO: 여기서 실제 광고 SDK 호출 (예: admob.rewarded.load().show())
  // 광고 시청 완료 콜백에서 grantAdReward() 호출
}
```

## 검증한 것 (v1.1)
- 헤드리스 Chrome(390×844, DPR 2)에서 클래식 모드·60초 타임어택 모두 실제 터치로 플레이
- 3턴 이하 / 10초 이하에서 붉은 맥박 비네트 표시, 4콤보에서 5초 피버 발동 및 점수 ×2(Δ점수 계산 일치) 확인
- 마스코트 5연타 이스터에그 발동(대사·젤리 변신), 같은 스테이지에서 재발동 안 됨
- 타임어택 60→0초 카운트다운, 0초 종료 모달, 광고 +15초 이어하기, `nyangJelly.bestTime.v1` 저장 확인
- 클래식 스테이지 클리어·남은 턴 보너스·게임오버·광고 +5턴 회귀 동작 확인
- 360×640, 390×844, 412×915에서 페이지 스크롤 없이 한 화면 유지, 콘솔 에러 0건
